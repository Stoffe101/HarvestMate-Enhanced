Gatherpedia fonts (optional)

Put these four files in this folder to get the full look. Without them,
Gatherpedia uses the game's own fonts.

  Marcellus-Regular.ttf
  AlegreyaSans-Regular.ttf
  AlegreyaSans-Medium.ttf
  AlegreyaSans-Bold.ttf

Both families are free under the SIL Open Font License and can be
downloaded from fonts.google.com (Marcellus, Alegreya Sans). Restart the
game after adding them.
